## 📖 Overview

The **Multilingual Language Translation System Using Transformers** is an AI-powered Neural Machine Translation (NMT) application designed specifically for Indian languages.

Built using **Meta AI's NLLB (No Language Left Behind) Transformer Model**, the system enables high-quality translation between **all 22 Scheduled Languages of India and English**.

The application combines **Natural Language Processing (NLP)**, **Deep Learning**, **Speech Processing**, and **Database Management** into a single end-to-end AI solution.

### ✨ Key Features

✅ Translation Across 22 Indian Languages + English

✅ Transformer-Based Neural Machine Translation

✅ Automatic Language Detection

✅ Speech-to-Text Conversion

✅ Text-to-Speech Output

✅ SQLite Translation History

✅ Streamlit Web Interface

✅ Fast Demo Mode + Transformer Mode

✅ End-to-End NLP Application

## 🎯 Problem Statement

India is one of the most linguistically diverse countries in the world. Communication barriers often arise when users need to access information, educational resources, government services, or digital platforms in different languages.

This project addresses this challenge by leveraging Transformer-based Neural Machine Translation to provide accurate multilingual communication across Indian languages.

---

## 💡 Solution

The system uses Meta AI's NLLB Transformer architecture to perform multilingual translation while preserving contextual meaning and semantic accuracy.

The platform integrates:

- 🌍 Text Translation
- 🎤 Voice Input
- 🔍 Language Detection
- 🔊 Voice Output
- 🗄️ Translation History
- ⚡ Real-Time Inference

## 🏛️ Architecture

```text
User Input
     │
     ├── Text Input
     └── Voice Input
             │
             ▼
     Language Detection
             │
             ▼
     Speech-to-Text
             │
             ▼
     NLLB Transformer
      (Encoder-Decoder)
             │
             ▼
      Translation Output
             │
     ┌───────┴────────┐
     ▼                ▼
Text Output    Voice Output
             │
             ▼
      SQLite Database
```

## 💼 Resume Description

Developed an India-focused multilingual language translation system using Meta AI's NLLB Transformer model, supporting translation across all 22 Scheduled Languages of India and English. Integrated automatic language detection, speech-to-text, text-to-speech, and SQLite-based translation history within a Streamlit web application. Implemented Transformer-based neural machine translation leveraging encoder-decoder architecture, self-attention, and sequence-to-sequence learning for accurate real-time multilingual communication.
